
# Geely Auto: Car Price Prediction

## Project Overview
This project uses Multiple Linear Regression to predict car prices based on vehicle attributes and explore the factors influencing automobile pricing.

## Business Objectives
- Predict car prices using available vehicle features.
- Identify variables associated with car prices.
- Evaluate model performance on unseen test data.

## Workflow
1. Data loading and inspection
2. Exploratory Data Analysis (EDA)
3. Data preprocessing and feature preparation
4. Train-test split and feature scaling
5. Multiple Linear Regression modelling
6. Model evaluation and residual analysis

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Statsmodels
- Jupyter Notebook

## Dataset
The analysis uses `CarPrice_Assignment.csv`. The dataset should be placed in the same folder as the notebook.

## How to Run
1. Install the required Python libraries using `pip install -r requirements.txt`.
2. Open `geely_auto_price_prediction.ipynb` in VS Code or Jupyter Notebook.
3. Run the notebook cells from top to bottom.

## Disclaimer
This project is an educational machine learning exercise. Model predictions and findings depend on the supplied dataset and analysis.
